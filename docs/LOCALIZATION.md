# Локализация оболочки (RU/EN)

## Правило: игровой текст — всегда из ROM

Игра не содержит наших текстов внутри игрового экрана. Всё, что рисует сама Dune
(меню, бриффинги, справка, названия домов, надписи в миссии), берётся из ROM игрока:

- США-версия (единственная поддерживаемая) — **английская**;
- русский игровой текст возможен **только** если игрок принесёт русский ROM (например,
  из Шедевра). Мы не поставляем и не вшиваем перевод: это чужие данные и чужие права.

## Что переводит оболочка

`web/i18n.mjs` переводит только наш слой: стартовый экран, прогресс сборки, готовность,
ошибки, паузу, сохранения, справку, кнопки/подписи HUD.

- Язык выбирается автоматически по `navigator.language`: `ru*` → русский, иначе английский.
- Кнопка `EN`/`RU` в шапке переключает язык; выбор сохраняется в `localStorage['dune.lang']`
  и применяется после перезагрузки (чтобы не оставалось полусмешанных экранов).
- Переводятся и динамические статусы через `t()` (сборка, сохранения, звук, ошибки);
  статические тексты — обходом DOM (`translateDom()`).
- Игровые команды (`REPEAT`, `CLEAR`, `EXIT`/`FIX`/`STOP`) остаются оригинальными
  английскими, как в игре, и не переводятся.

## Справка «Как играть»

Лист справки (`#help-sheet`) открывается со стартового экрана («Как играть») и из паузы
(«Справка»). Содержание: что нужно (свой ROM), управление (меню, карта, пан/зум, двойной
тап по зданию), пауза/автосейв. Это наш текст, он переводится вместе с оболочкой.

## Проверка

```sh
node tests/browser/i18n.mjs                 # локально
PLAY_URL="https://superoles-red.github.io/dune-web/" node tests/browser/i18n.mjs   # на Pages
```

Тест проверяет: `ru-RU` браузер → русский по умолчанию; переключение на EN (заголовок,
кнопки, справка, пауза) и обратно; `en-US` браузер → английский по умолчанию; лист
справки открывается и переводится. ROM не нужен.

## Ограничения

- Переводится только оболочка; если игрок принёс английский ROM, внутриигровые экраны
  останутся английскими (это оригинал).
- Логи в «Подробностях» — технические, остаются на русском.
- Названия домов и игровые термины в оболочке (ATREIDES и т.п.) не переводятся.
