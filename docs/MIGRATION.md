# Перенос сохранений из старой версии

Старая версия (`superoles-red/dune-sega-web`) и новый BYOP-порт используют один и тот же формат
файла сохранения и одинаковый нативный ABI (`DSAV` v2). Поэтому сохранения переносятся **без
конвертации**: новый порт просто принимает старый файл.

## Способ 1 — файл (надёжный, работает между устройствами)

1. Откройте **старую** версию игры в браузере, где лежит ваше сохранение.
2. `OPTIONS` → `FILES & OFFLINE` → `DOWNLOAD SAVE`. Получится файл вида
   `dune-2026-…T…Z.dune-save.json`.
3. Откройте **новую** версию (`dune-web`) → раздел «Сохранения» → выберите этот файл →
   «Импортировать сейв».
4. Появится описание: дом, текущая миссия, прогресс всех домов. После подтверждения данные
   записываются в браузер новой версии.

Экспорт из новой версии делается той же кнопкой «Экспортировать» — это тот же формат файла
(с теми же правилами и checksum), но с идентичностью **нового** порта в блоке `compatibility`.
Старая версия такой файл не примет (у неё свой список разрешённых сборок): совместимость
односторонняя, old→new. Экспорт из новой нужен для резервной копии и переноса между
устройствами, где открыта новая версия.

## Способ 2 — автоматически (если обе версии на одном домене)

Страницы `superoles-red.github.io/dune-sega-web/` и `superoles-red.github.io/dune-web/` — один
origin, поэтому `localStorage` у них общий. Новый порт при старте читает старые ключи
(`dune-sega-campaign-v1`, `dune-sega-continue-v2`, `dune-original-aot-state-v2`) и предлагает
продолжить: прогресс и текущая миссия уже на месте.

Если новая версия открыта с другого адреса (локальный сервер, другой домен), используйте способ 1.

## Что переносится

- общий `CONTINUE` (активная миссия, снапшот состояния игры);
- прогресс всех трёх домов: открытые и пройденные миссии, даты прохождения;
- язык интерфейса (`en`/`ru`);
- настройки звука — отдельно, они не входят в файл сохранения.

## Что важно знать

- Файл сохранения содержит снимок эмуляции (регистры, RAM, VDP, звук) — это данные игры;
  в репозитории и на сервере он не хранится и не передаётся, только в вашем браузере.
- Если файл от другой версии игры/сборки, импорт откажется с понятной ошибкой
  («СОХРАНЕНИЕ ОТ НЕСОВМЕСТИМОЙ ВЕРСИИ» / «ПОВРЕЖДЁН»).
- Импорт заменяет текущее сохранение и прогресс новой версии (старые ключи браузера при этом
  не удаляются). Перед импортом можно экспортировать текущее состояние как резервную копию.
- После импорта миссия продолжится с того же места: это тот же ROM и тот же формат состояния.

## Если сохранение не переносится

1. Проверьте, что файл получен кнопкой `DOWNLOAD SAVE` старой версии, а не скопирован
   из `localStorage` вручную.
2. Убедитесь, что файл не редактировался: checksum `sha256` защищает от изменений.
3. Сообщите ошибку (код из сообщения: `incompatible-payload`, `invalid-payload`,
   `checksum-mismatch`, `mission-mismatch`) — формат сохраняется намеренно, такие случаи
   разбираются точечно.
