# PWA и офлайн-режим

BYOP-порт можно установить на телефон и запускать без сети после первого визита.

## Что кэшируется

`web/sw.js` (cache `dune-byop-v1`) кэширует:

- оболочку: `index.html`, `app.mjs`, `input/*`, `host/*` (включая аудио-ворклет);
- рантайм: `runtime/runtime.wasm`, `loader.mjs`, `abi.json`, `game-reference.json`;
- собранный Pyodide-пакет: `py-package.zip`, `reference.json`;
- **дистрибутив Pyodide** из `vendor/pyodide/` — он попадает в кэш при первой сборке;
- иконки и `manifest.webmanifest`.

Не кэшируется и никогда не запрашивается по сети: **ROM игрока** (это локальный `File`) и
сгенерированный `game.wasm` — он лежит в OPFS в ключе `dune-web/rom-<sha256>` и переиспользуется
офлайн (`web/recompiler.worker.js`).

При навигации сервис-воркер сначала идёт в сеть, при отсутствии — отдаёт кэшированный
`index.html`. Остальные GET-запросы того же origin — cache-first с докэшированием
(`stale-while-revalidate` на практике: из кэша сразу, обновление — при следующем запросе).

## Установка

- Chrome/Edge (Android, десктоп): кнопка **«Установить на телефон»** на стартовом экране
  (появляется, когда браузер предлагает `beforeinstallprompt`), либо меню браузера →
  «Установить приложение».
- iOS/Safari: «Поделиться» → «На экран Домой».

`manifest.webmanifest`: `display: standalone`, `orientation: any`, `start_url: ./`,
иконки 192/512 + maskable, `theme_color #120d08`.

## Проверка

```sh
DUNE_ROM="/path/to/Dune (USA).gen" node tests/browser/offline.mjs
```

Тест делает: онлайн-сборку (кэширует Pyodide и vendor) → `context.setOffline(true)` →
перезагрузку (страница обязана загрузиться из SW) → повторный выбор ROM → сборка должна
прийти из OPFS (`cached: true`, секунды → 0) → запуск игры и кадры в офлайне. Проверяются
кэш (27+ записей, ≥3 файла Pyodide), контроллер SW и манифест.

## Ограничения

- Первый визит всё равно требует сети (загрузка Pyodide ~12 МБ и сборка ядра).
- Очистка данных сайта браузером удаляет и кэш, и OPFS.
- На iOS standalone-режим имеет свои ограничения WebAudio/жестов — звук включается после
  первого тапа (кнопка «Играть»).
