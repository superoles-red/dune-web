# Проверка кампании (автоматизированная)

Полное прохождение 9 миссий вручную в CI не автоматизируется, поэтому
кампанийный путь проверяется тремя уровнями: продолжение после перезагрузки,
длительная стабильность и полный e2e миссии с HUD/меню/сохранениями.

## 1. Continue кампании — `tests/browser/continue.mjs`

Сценарий (Roman: телефонный вьюпорт 390×844, DPR 2):

1. ROM → сборка ядра в браузере;
2. меню → выбор дома → вступление → **миссия 1** (`campaign_json`: `armed=1`,
   `house=Atreides`, `mission=1`);
3. пауза → **Сохранить** (нативный DAV v2, 140 056 Б + YM);
4. **полная перезагрузка страницы** (новый процесс), повторный выбор ROM,
   сборка из OPFS-кэша;
5. на стартовом экране кнопка **«Продолжить»**;
6. восстановленная кампания: `armed=1`, тот же дом и миссия;
7. выбор здания даёт HUD, камера прокручивается.

Результат: **CONTINUE OK** локально и на живом GitHub Pages.

## 2. Soak-стабильность — `tests/browser/soak.mjs`

24 раунда по 2 млн инструкций 68000 на миссии с прокруткой/зумом камеры,
двойными тапами по заводу (открытие/закрытие нативной консоли) и
периодическими сохранениями через паузу.

Результат (headless Chrome, телефонный вьюпорт):

| метрика | значение |
|---|---|
| просимулировано | **65 744 007** инструкций 68000 (мастер-циклы 9.21 млрд) |
| нативных кадров | **5 752** (fps ~36 в headless с постоянными жестами) |
| fault / stall | **0 / 0** |
| wasm-память | 64 МиБ → 64 МиБ (**+0**) |
| JS heap | ~10.9 МБ → ~9.4 МБ (без роста) |
| миссия после soak | `armed=1`, scene=map |

`SOAK OK`.

## 3. Миссия e2e — `tests/browser/play.mjs`

Сборка → меню → дом → вступление → миссия → HUD `REPEAT` (нативный счётчик B
увеличился) → двойной тап → консоль здания (18 нативных ячеек, ячейка принята)
→ `EXIT` → поворот портрет/ландшафт → пан/зум/тап → сохранение → загрузка.
`PLAY OK` локально и на Pages.

## Ограничения

- Реальное прохождение миссий (экономика, бои, переходы 1→9) требует часов игры;
  автоматизация проверяет механику продолжения, сохранения и стабильность, а не
  баланс кампании.
- Часть звуковых событий (музыка/речь) проверена метриками (RMS/peak, уровни),
  а не на слух.
- Разные дома (Harkonnen/Ordos) проходят тот же нативный код; выбор дома
  проверялся через e2e Atreides, ручной прогон других домов — на телефоне.
