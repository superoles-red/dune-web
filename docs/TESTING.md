# Что проверить в опубликованной тестовой сборке

Сборка: https://superoles-red.github.io/dune-web/
Статус: этап 2/3 — проверяются **сборка ядра из ROM** и **перенос сохранений**. Игра пока не
рендерится (это следующий этап), поэтому «чёрный экран вместо игры» — ожидаемо.

## 1. Сборка ядра из ROM (главное)

1. Откройте ссылку. В разделе «1. ROM» выберите свой `Dune - The Battle for Arrakis (USA).gen`
   (1 048 576 байт). Файл не покидает устройство.
2. Паспорт дампа должен показать: размер `1 048 576 Б (1.0 МиБ)`, SHA-256
   `b1bbe731…c335ba`, «поддерживается, полный режим».
3. Нажмите «Собрать ядро». Ожидаемое:
   - прогресс по фазам: Pyodide → распаковка → проверка ROM → поиск точек входа (68000) →
     трансляция и генерация → SHA-256 → кэширование;
   - вердикт «**СОВПАДАЕТ с эталонным ядром**», SHA `d7c84066…ebbd123`, размер
     `20 417 216 Б`;
   - на ПК на M1 сборка ~8–10 с; на телефоне — минуты (проверьте, сколько именно);
   - «Всего» — время; в журнале строки `translated=40382 instructions`,
     `Z80 translated=3095 guarded instruction variants`.
4. Нажмите «Собрать ядро» ещё раз: должно быть почти мгновенно и с пометкой
   «из кэша» (ядро хранится в OPFS этого браузера). Кнопка «Удалить собранное ядро из кэша»
   сбрасывает кэш — после неё сборка идёт заново.

Что сообщить, если не так: устройство/браузер/версию, на каком шаге остановилось, текст из
«Журнала», сколько заняло, сколько памяти (если видно).

## 2. Перенос старого сохранения

1. В **старой** версии (`dune-sega-web`) откройте `OPTIONS` → `FILES & OFFLINE` →
   `DOWNLOAD SAVE`. Получится `dune-…dune-save.json`.
2. В новой сборке, раздел «3. Сохранения», выберите этот файл → «Импортировать сейв».
3. Ожидаемое: «Импортировано: текущая миссия: <дом> <номер> · <дом>: открыто N/9, пройдено M.
   Язык: …». Файл старой версии принимается **как есть**, без конвертации.
4. «Экспортировать» — скачивает текущее сохранение в том же формате. Это резервная копия и
   перенос между устройствами/браузерами; старая сборка такой файл не откроет (односторонняя
   совместимость old→new — намеренно).

Если новая сборка открыта на том же домене `superoles-red.github.io`, что и старая игра,
прогресс из `localStorage` может подхватиться автоматически: в разделе сохранений появится
«В браузере уже есть сохранение: …».

## 3. Что НЕ проверяется на этом этапе

- Запуск игры, карта, юниты, звук, тач-управление — следующий этап (игровая оболочка).
- Офлайн/PWA — появится позже.
- Samsung Internet: по опыту старой версии может падать на WASM — используйте Chrome.

## 4. Известные ограничения

- GitHub Pages не отдаёт COOP/COEP, поэтому строка «Память страницы» может отсутствовать;
  на сборку это не влияет.
- Первая сборка качает Pyodide (~12 МБ) из репозитория — на мобильной сети это время.
- Кэш привязан к браузеру и профилю; очистка данных сайта удаляет и кэш, и сохранения
  (экспортируйте файл заранее).
